# Subagent Dispatch

- Deep work is slow by nature: review, architecture, diagnosis. Silence is not stalling; let subagents run to complete.
- Re-review a fix through the same idle reviewer; send only the fix and unchecked scope.
- Wide fan-out runs as two concurrent waves: dispatch two to four slices covering the distinct kinds, read their artifacts against the brief, adjust if needed, then fan the remainder at full width.

# Briefs

- State the minimum-change constraint and the conventions to match. Subagents start blank and default to over-building.
- Ask for the change and its evidence, not a report.
