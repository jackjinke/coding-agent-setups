# Subagent Dispatch

- Complex implementation work has no fixed deadline; do not interrupt while meaningful progress continues.
- Timeline while review task does not return: 10min ask to converge; 15min demand the verdict with settled findings and unchecked scope named; 25min cancel and take partial.
- Re-review a fix through the same idle reviewer; send only the fix and unchecked scope, then follow its live transcript for the next verdict.
