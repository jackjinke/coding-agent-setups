# Mid-task questions

When a user question arrives mid-task, answer it directly (quick read-only checks are fine; do not start heavy investigation without replying first):
- If the question challenges the approach, scope, or direction, pause task mutations, note any unfinished work in one line, and wait for an explicit go-ahead.
- If the question has no intent to stop or redirect the work, answer it and continue advancing the task (including as background tasks complete).
